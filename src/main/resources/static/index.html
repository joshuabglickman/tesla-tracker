Set up

You only do this once. After that, mileage is recorded automatically while this app runs.

  1. Create a Tesla developer app
    At developer.tesla.com, create an application:
    • Allowed origin: the HTTPS domain where you'll publish the public key (step 2), e.g. https://yourname.github.io
    • Allowed redirect URI:
    • Scopes: Vehicle Information and Vehicle Location (plus offline access)
    Put the Client ID and Client Secret in config/application.properties (copy it from the .example file), then restart the app.
  2. Publish this public key
    Tesla requires it at https://YOUR-DOMAIN/.well-known/appspecific/com.tesla.3p.public-key.pem. The README describes a free way to host it on GitHub Pages.
  3. Register the app with Tesla
  4. Connect your Tesla account
    Connect Tesla

Named places

Use "Name this place" next to any address to label it (e.g. Home or Work). Any position within 150 m of a named place gets that name.
